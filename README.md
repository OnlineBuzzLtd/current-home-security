# CURRENT Home Security

Premium home-security landing site for alarm and CCTV installations across South London.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

Import this repository into Vercel as a Next.js project. Add:

```text
NEXT_PUBLIC_SITE_URL=https://yourdomain.co.uk
```

Then connect the final domain in Vercel project settings.

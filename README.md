# CURRENT Home Security

Premium home-security website for alarm and CCTV installations across South London.

## Local development

```bash
npm install
npm run dev
```

## Vercel deployment

Import this repository into Vercel as a Next.js project, then add:

```text
NEXT_PUBLIC_SITE_URL=https://yourdomain.co.uk
```

Connect the final domain in Vercel project settings and redeploy.
